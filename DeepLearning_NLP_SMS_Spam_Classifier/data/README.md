# Dataset

This project uses the **SMS Spam Collection** from the UCI Machine Learning Repository.

- 5,574 SMS messages
- Classes: `ham` (not spam) and `spam`
- Task: binary text classification
- Source: UCI Machine Learning Repository
- DOI: https://doi.org/10.24432/C5CC84

The notebook automatically downloads the dataset from UCI if it is not already present.

After running the notebook, the processed CSV will be saved as:

`data/sms_spam.csv`

Dataset attribution:
Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection. UCI Machine Learning Repository.
