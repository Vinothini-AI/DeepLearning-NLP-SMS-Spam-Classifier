# Deep Learning / NLP Text Classifier with PyTorch

## Project title
**SMS Spam Detection using TF-IDF and a Deep Learning Neural Network with PyTorch**

## Objective
Build an NLP text-classification pipeline that:
1. Loads a real SMS dataset.
2. Cleans and prepares the text.
3. Converts text into numerical features using TF-IDF.
4. Trains a multi-layer neural network using PyTorch.
5. Uses Batch Normalization and Dropout.
6. Uses Early Stopping to reduce overfitting.
7. Plots training/validation loss and accuracy.
8. Evaluates the model on unseen test messages.
9. Displays classification confidence for new SMS messages.

## Dataset
**SMS Spam Collection – UCI Machine Learning Repository**

The dataset contains 5,574 labeled SMS messages. The two classes are:
- `ham` = normal message
- `spam` = unwanted/spam message

Official source:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

DOI:
https://doi.org/10.24432/C5CC84

## How to run in VS Code

### 1. Open the project folder
Open `DeepLearning_NLP_SMS_Spam_Classifier` in VS Code.

### 2. Create a virtual environment
Open the VS Code terminal:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install packages

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Open Jupyter Notebook

```bash
python -m notebook
```

Open:

`notebooks/SMS_Spam_DeepLearning_PyTorch.ipynb`

Run the cells from top to bottom.

## What the notebook produces

You will get:
- Dataset shape and sample rows
- Class distribution
- TF-IDF feature size
- Neural-network architecture
- Training/validation loss curve
- Training/validation accuracy curve
- Test accuracy, precision, recall and F1-score
- Confusion matrix
- Predictions on unseen SMS messages
- Spam/ham confidence percentage
- Saved model and TF-IDF vectorizer

## Important
The exact accuracy and loss values can change slightly between runs because neural-network training is stochastic. Use the results generated by **your own run** in your report and screenshots.
